# REX — реверс-инжиниринг книг Excel

Открываете чужую книгу на 200 листов и не понимаете, откуда берутся числа.
REX разбирает её целиком и показывает: что в ней есть, что откуда питается,
что сломано и что можно выбросить.

**Файл не покидает компьютер.** Весь разбор идёт в браузере; сеть нужна один
раз — подтянуть библиотеки с CDN. Ни байта книги никуда не уходит.

## Как пользоваться

Скачайте `REX_v2.4.6.html` и откройте в браузере. Больше ничего не нужно:
ни установки, ни сервера, ни учётной записи. Перетащите книгу в окно.

Форматы: `.xlsx`, `.xlsm`, `.xlsb`, `.xls`, `.xltx`. Из двух последних часть
сведений не достать — так устроен формат, и на вкладке «Загрузка» честно
расписано, что именно теряется.

## Что он показывает

| раздел | о чём |
|---|---|
| **Обзор** | паспорт файла и индекс здоровья: пять оценок и из чего каждая сложилась |
| **Граф связей** | кто у кого берёт данные — листы, таблицы, запросы, сводные, имена |
| **Листы и таблицы** | инвентарь книги и что из него ни на что не влияет |
| **Формулы и ссылки** | разбор по колонкам: где протянутую формулу подменили руками; матрица ссылок между листами; внешние книги |
| **Power Query** | все запросы, их источники и шаги, выгрузка M-кода |
| **Модель данных** | таблицы и меры Power Pivot (выражения DAX из файла не достать — это ограничение формата) |
| **Качество данных** | правила: `#REF!`, ошибки в ячейках, ручной пересчёт, летучие функции, ссылки на целые колонки, скрытые листы и имена |
| **Очистка книги** | разбор мусорных имён по происхождению и **макрос, собранный под вашу книгу** |
| **Сравнение версий** | чем одна версия отличается от другой, вплоть до контрольных сумм частей архива |
| **Отчёт** | паспорт книги в Markdown, граф в JSON, реестр находок в CSV |

### Про очистку

Скрытые имена (`hidden="1"`) Excel не показывает в Диспетчере имён ни при
каком фильтре — выделить и удалить их нечем, остаётся макрос. Удалять «всё
скрытое» одной кнопкой опасно: среди скрытых есть рабочие — служебные имена
диаграмм, модель «Поиска решения», имена, на которых держится условное
форматирование.

Поэтому REX не даёт одной кнопки, а раскладывает имена по происхождению с
оценкой риска. Вы выбираете группы — он собирает макрос. Макрос запускается
дважды: первый раз строит лист со списком того, что собирается удалить, и
только на втором запуске спрашивает подтверждение. Ничего не удаляется молча.

## Что внутри

Один HTML-файл. Библиотеки — с jsDelivr, с проверкой `integrity`:

- [fflate](https://github.com/101arrowz/fflate) — распаковка OOXML;
- [cytoscape.js](https://js.cytoscape.org/) + dagre — граф связей;
- [SheetJS](https://sheetjs.com/) — только для `.xls`/`.xlsb`, грузится лениво.

Разбор идёт по сырому XML внутри ZIP: `workbook.xml`, листы, таблицы, связи,
`DataMashup` с M-кодом запросов. Ничего не додумывается — если сведения из
файла не достаются, раздел так и говорит.

```bash
cd tests && npm install && npm run setup && npm test
```

Восемь наборов, около 35 секунд, подробности — в [tests/README.md](tests/README.md).

## Версии

Файл называется по версии: `REX_vX.Y.Z.html`. Минорная цифра не переходит за
девять — после `v1.9.x` идёт `v2.0.0`. Что менялось и почему — в истории
коммитов; там разобрано каждое решение, включая отменённые.
